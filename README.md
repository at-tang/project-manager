# Project Manager
---
Project Manager is a Productivity mobile application designed using Swift & the SwiftUI Framework. The app allows users to neatly organize and modularize their long-term projects into separate categories, each containing their own lists of highly-customizable tasks.

## Features
---
- Integration with Apple Photos; Add photos as attachments to specific tasks 
- An iOS Widget allowing you to access your latest edited Project
- Automatically saved, local data through SwiftData
